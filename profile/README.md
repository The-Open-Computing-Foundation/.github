# The Open Computing Foundation

**Independent computing. Open systems. Universal compatibility.**

The **Open Computing Foundation (OCF)** is an independent, nonprofit-oriented computing organisation founded by **Colm Lenehan** and guided by the collective work, research, and contributions of its contributors.

OCF is dedicated to advancing computing independence, software interoperability, open technical standards, and the long-term accessibility of digital technology.

We believe that software should not be unnecessarily confined to a particular operating system, hardware architecture, execution environment, or proprietary platform.

Our work focuses on investigating how existing technologies can be adapted, preserved, and made accessible across computing environments, with particular emphasis on the open web.

## The Web Independence Initiative

**Our principal undertaking is The Web Independence Initiative (WII).**

The Web Independence Initiative is a long-term technical research and development effort concerned with one fundamental objective:

**Making existing software, applications, games, operating environments, and digital technologies compatible with and, wherever technically feasible, native to the web.**

Modern computing is divided between operating systems, hardware architectures, application frameworks, proprietary runtimes, and platform-specific dependencies.

Software designed for one environment frequently cannot operate in another without substantial modification, emulation, or redevelopment.

WII investigates how these boundaries can be reduced through standards-based web technologies, compatibility infrastructure, software porting, emulation, and alternative execution environments.

The objective is not to reproduce the appearance of existing software inside a browser. It is to enable genuine software functionality through technically sound implementations.

### Project Ubiquity

**Ubiquity** is the central technical research and development project of The Web Independence Initiative.

Ubiquity investigates the execution, adaptation, and interoperability of existing software within web-compatible environments.

Its areas of interest include:

- **Operating systems:** Investigating the execution of genuine operating systems and their software environments through web technologies.
- **Application compatibility:** Exploring methods for executing or porting existing desktop and mobile applications.
- **Game compatibility:** Researching browser-based execution of existing games, graphics systems, input interfaces, and runtime dependencies.
- **WebAssembly:** Investigating portable execution, binary translation, and browser-hosted runtimes.
- **Compatibility layers:** Developing and evaluating abstractions between existing software interfaces and web platform capabilities.
- **Emulation and virtualisation:** Examining approaches to executing software originally designed for different hardware and operating environments.
- **Web-native implementations:** Adapting existing functionality to standards-based browser environments without sacrificing essential capabilities.
- **Software preservation:** Supporting continued access to software that might otherwise become difficult to execute on contemporary systems.

Ubiquity is an ongoing research undertaking. Its objectives describe intended areas of development, not a claim of universal compatibility or completed implementation.

### Initial Research: Linux on the Web

An initial major research objective is the execution of a genuine Linux environment within a web browser.

The proposed investigation includes Linux kernel execution, userspace compatibility, virtual hardware, filesystem access, browser-based execution engines, and graphical environments.

The emphasis is on running real software rather than constructing simulated interfaces.

This work is intended to establish a technical foundation for broader operating-system and application compatibility research.

## Research and Engineering

OCF's areas of technical interest include:

| Area | Research focus |
|---|---|
| Operating Systems | Kernel execution, userspace environments, system interfaces |
| Computer Architecture | Instruction sets, emulation, binary translation |
| Web Technologies | WebAssembly, WebGPU, browser APIs, Web Workers |
| Software Compatibility | Portability, runtime dependencies, compatibility layers |
| Systems Programming | Memory management, filesystems, process execution |
| Graphics and Input | Rendering pipelines, display systems, device abstraction |
| Networking | Protocol interoperability, browser networking limitations |
| Digital Preservation | Maintaining access to existing software and computing environments |
| Security | Isolation, sandboxing, trusted execution boundaries |
| Open Standards | Interoperability, documentation, long-term portability |

Research should be reproducible, technically documented, and transparent about limitations.

**A demonstration is not a compatibility guarantee. A mockup is not an implementation. An objective is not an achievement.**

## An Organisation Built Around Contributors

The Open Computing Foundation was founded by Colm Lenehan, but its intended direction is collective.

OCF is not conceived as a conventional commercial software company or a founder-centred product organisation.

Its long-term purpose is to provide an environment in which programmers, systems engineers, researchers, designers, technical writers, and other contributors can collaborate on difficult computing problems.

Our principles include:

1. **Technical integrity.** Claims should be supported by functioning implementations, reproducible experiments, or credible evidence.
2. **Openness.** Research and documentation should support understanding, scrutiny, and further development.
3. **Interoperability.** Computing environments should communicate and cooperate wherever technically possible.
4. **Independence.** Users should have meaningful choices concerning the platforms and technologies they depend upon.
5. **Collaboration.** Technical direction should benefit from constructive contributions and review.
6. **Responsible engineering.** Security, licensing, software ownership, and maintainability must remain fundamental considerations.

Contribution processes and project-specific development policies will be documented as the organisation's infrastructure develops.

## Current Direction

OCF's immediate focus is the technical groundwork for The Web Independence Initiative and Ubiquity.

This includes evaluating browser execution technologies, identifying architectural constraints, documenting compatibility approaches, and pursuing practical implementations.

The scope is intentionally ambitious. Not every existing program, operating system, or hardware-dependent application can necessarily be executed through current browser technologies.

These limitations are subjects for engineering investigation, not reasons to substitute simulated behaviour for functional software.

The objective is to expand what the web can genuinely execute, one verified implementation at a time.
